## (개인·필수) 문제 1 — 공통 원본을 보존하고 개인본 만들기

공통 Dashboard를 `Save as` 또는 `Duplicate`하여 개인본을 만드세요. 공통 원본에 덮어쓰지 않습니다.

- 공통 원본 이름: D4 공통 상품 Dashboard - 정연
- 개인본 이름 `D4 개인 미션 - 주제 - 이름`: D4 개인 미션 - Beauty Finder - 정연
- 사용한 복제 방법: Save as (새 이름으로 저장, 원본에 덮어쓰지 않음)
- 상단 제목이 개인본으로 바뀌었는가: 예
- Dashboard 목록에 원본과 개인본이 모두 있는가: 예 (공통본·개인본 2개 모두 존재)
- 캡처 파일: `../captures/p-p07-dashboard.png`

## (개인·필수) 문제 2 — 청사진대로 서로 다른 패널 4개 제작

질문 Q1~Q4를 답하는 패널을 최소 4개 만드세요. 공통 Dashboard와 비교해 field·집계·정렬·구간·제목 중 두 가지 이상을 개인 질문에 맞게 바꿉니다.

| 질문 | 패널 제목 | field | 계산·그룹 | 차트 | 실제 결과 | 완료 기준 통과 |
|---|---|---|---|---|---|---|
| Q1 | 검색 대상 화장품 수 | (Records) | Count | Metric | 1,000 | 통과 |
| Q2 | 카테고리별 상품 수 | category | Top 8 + Count | Bar(가로) | 블러셔 187 최다 | 통과 |
| Q3 | 브랜드별 상품 수·평균가격·평균평점 | brand, price, rating | Top 10 + Count + Avg | Table | 롬앤 111(₩31,329, ★3.41) | 통과 |
| Q4 | 퍼스널컬러별 상품 비율 | personal_color | Top 4 + Count | Donut | 겨쿨 263(26.3%) | 통과 |

- 공통본에서 변경한 요소 2개 이상: ① Data View를 products→beauty-products로 교체 ② Table에 Average rating 열 추가 ③ Donut field를 in_stock→personal_color로 교체 ④ 시간 범위를 2023-01-01~2026-09-03으로 확장
- 만들지 못한 패널과 이유: 없음 (Q1~Q4 모두 제작)
- 사용한 대체 질문 또는 데이터 보강 계획: 판매·시간 분석은 sales_count 보강 후로 미룸(6교시 문제4 참조)

## (개인·필수) 문제 3 — 제목과 배치만 보고 질문을 이해하게 만들기

각 제목을 `Bar`, `그래프`, `현황` 같은 차트 이름이 아니라 사용자가 알게 되는 내용으로 바꾸세요.

| 수정 전 제목 | 수정 후 제목 | 사용자가 알게 되는 것 |
|---|---|---|
| Metric | 검색 대상 화장품 수 | 고를 수 있는 상품이 총 1,000개 |
| category Bar | 카테고리별 상품 수 | 블러셔·립틴트에 상품이 가장 많음 |
| brand Table | 브랜드별 상품 수·평균가격·평균평점 | 롬앤이 최다, 브랜드별 가격·평점 차이 |
| personal_color Pie | 퍼스널컬러별 상품 비율 | 겨쿨 상품이 가장 많음(26.3%) |

- 가장 중요한 패널: 브랜드별 Table (구매 결정에 직접 쓰임)
- 가장 크게 배치한 이유: 열이 3개(상품 수·평균 가격·평균 평점)라 넓어야 값이 잘리지 않음
- 잘림·겹침을 수정한 패널: 카테고리 Bar를 가로 막대로 바꿔 한글 카테고리명 잘림 해소
- 수정 후 전체 화면 캡처: `../captures/p-p07-dashboard.png`

## (개인·필수) 문제 4 — 개인 질문용 Control 또는 Filter

사용자가 반복해서 바꿀 조건 하나를 Control로 만들거나, 항상 유지할 조건 하나를 Filter로 추가하세요.

- 선택한 방식: Control
- field: personal_color
- label 또는 조건: 퍼스널컬러 선택
- 이 조건이 필요한 사용자 행동: 소비자가 자기 퍼스널컬러(겨쿨 등)로 반복해서 상품을 좁힘
- 적용 전 핵심값: 전체 1,000
- 적용 후 핵심값: personal_color = 겨쿨 → 263
- 함께 변한 다른 패널: 카테고리 Bar(블러셔 187→46), 브랜드 Table, 퍼스널컬러 Donut
- 해제 방법: Control을 Any로
- 해제 후 복구값: 1,000
- 캡처 파일: `../captures/p-p07-control.png`

## (선택 도전) 문제 5 — 확장 차트 하나의 필요성 심사

Gauge, Heatmap, Treemap, Tag cloud 중 하나가 자신의 질문에 정말 필요한지 먼저 판단하세요.

- 후보 차트: Heatmap
- 답하려는 질문: 퍼스널컬러 × 카테고리 조합별 상품 수는 어떻게 분포하는가
- 필요한 field: personal_color, category (둘 다 keyword)
- 기본 Bar/Table보다 나은 점: 두 범주의 교차 분포를 색 농도로 한눈에 봄(예: 겨쿨×립틴트 50)
- 오해할 위험: 색 농도 차이가 작으면 셀 간 구분이 어려움
- 추가/보류 결정: 보류 — 현재 핵심 질문(카테고리·브랜드 우선순위)은 Bar/Table로 충분
- 추가했다면 검증 결과: (보류)

질문에 필요하지 않으면 만들지 않는 것도 정상 답입니다.
