# Pipeline 적용 판단 (T16)

## 판단 결과: 미적용

## 이유

beauty-products의 데이터는 Python 생성기로 합성한 데이터이며, 색인 전에 이미 정제된 형태로 만들어진다.

- `product_name`은 생성기에서 `{brand} {category} {sequence}` 형태로 직접 생성
- `rating`, `price` 등 숫자 field는 생성 시점에 이미 올바른 타입으로 생성
- 변환이 필요한 원본 데이터(CSV, 로그 등)가 없음

따라서 ingest pipeline을 별도로 적용하지 않아도 색인이 정상적으로 이루어진다.

## pipeline이 필요했을 경우 (가정)

실제 올리브영 크롤링 데이터를 사용했다면 아래와 같은 pipeline이 필요했을 것:
- 가격 문자열 `"13,000원"` → 숫자 `13000` 변환
- 날짜 형식 통일 (`2026.03.01` → `2026-03-01`)
- 태그 문자열 분리 (`"촉촉함,발색"` → `["촉촉함", "발색"]`)
