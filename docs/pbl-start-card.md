# PBL 시작 카드

- 프로젝트 주제: 사용자 조건 기반 화장품 검색 및 분석
- 사용자는 누구인가: 자신에게 맞는 화장품을 찾으려는 소비자
- ES로 찾게 할 문서 1건은 무엇인가: 화장품 상품 정보 1건 (제품명·브랜드·카테고리·퍼스널컬러·피부타입·가격·평점·리뷰수·태그)
- 사용자가 입력할 검색 질문 1: 촉촉한 봄웜 립틴트
- 사용자가 입력할 검색 질문 2: 지속력 좋은 코랄 블러셔
- 사용자가 입력할 검색 질문 3: 2만원 이하 평점 좋은 아이섀도우
- 필터에 사용할 분류 필드 후보: category, brand, personal_color, skin_type
- 정렬에 사용할 숫자·날짜 필드 후보: price, rating, review_count, release_date
- Dashboard에서 답할 질문 1: 어떤 카테고리와 퍼스널컬러의 제품이 가장 많고 평점이 높은가?

## 범위 확인

- 웹사이트 전체를 만드는 과제가 아닙니다. ES index, 검색 요청, 분석·Dashboard를 완성합니다.
- 실제 개인정보·고객 데이터는 사용하지 않습니다.
- 최소 1,000건, 권장 5,000~10,000건의 합성 데이터를 사용합니다.
